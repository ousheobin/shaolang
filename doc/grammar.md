# ShaoLang 语言语法

配套文档：[编译器设计文档](compiler-design.md) · [English version](grammar_EN.md)

---

## 1. 词法

### 1.1 源文件与空白

- 源文件是纯文本，按字节流读取；非 ASCII 字节（如 UTF-8 中文注释）被当作普通字符，只有 (char)-1 是文件结束哨兵。
- 空白字符只有四种：空格、制表符、回车、换行。词法分析在取记号前跳过空白。
- 一个命令行可以传入多个源文件，但**每个文件独立编译**，文件之间不共享符号表。

### 1.2 注释

```
// 行注释，到行尾结束
/* 块注释，可以跨行，不支持嵌套；缺少 */ 会报 "注释没有结束" */
```

注释在 read_operator() 里遇到 / 时识别，识别后不产生任何记号。

### 1.3 标识符与关键字

```
identifier ::= (letter | '_') (letter | digit | '_')*
letter     ::= A-Z | a-z
```

- 区分大小写；**不允许以数字开头**（2fast 报错 ShaoLang不允许使用数字作为标识符的开头）。
- 关键字全部为保留字，不能作标识符：

| 类别 | 关键字 |
|---|---|
| 类型 | int char void |
| 选择/循环 | if else while |
| 流程跳转 | break continue return |
| 输入输出 | input output |

### 1.4 字面量

| 形式 | 记号 | 规则 |
|---|---|---|
| 123 | C_INTEGER | 只支持十进制非负整数；值必须 ≤ INT_MAX；不支持浮点数（1.5 报错 ShaoLang不支持浮点数），负号由一元运算符表达 |
| 'a'、换行转义 | C_CHAR | 单引号内恰好一个字符或一个转义；空/未闭合报错 |
| "abc" | C_STRING | 双引号内不能跨行；转义后按字符序列存储 |

支持的转义见下表（字符与字符串共用）；反斜杠后跟无法识别的字母时，直接取那个字母：

```
\\   \n   \r   \t   \"   \'   \0
```

### 1.5 运算符与界符

| 字符 | 记号 | 文法中的角色 |
|---|---|---|
| + - * / % | ADD SUB MUL DIV MOD | 算术二元运算；- 还可作一元取负，* 还可作一元解引用与指针声明符 |
| ++ -- | INC DEC | 前缀/后缀自增自减 |
| ! | NOT | 逻辑非 |
| && \|\| | AND OR | 逻辑与、逻辑或 |
| > >= < <= == != | GT GE LT LE EQ NEQ | 关系/相等比较 |
| = | ASSIGN | 赋值 |
| & | LEA | 一元取地址（§2.4） |
| \| | — | **非法字符**，报错 符号'\|'不是ShaoLang可用的运算符（只有 \|\| 合法） |
| << >> | LEFT_STREAM RIGHT_STREAM | 词法可识别，**文法未使用** |
| , ; : | COMMA SEMICOLON COLON | , 用于声明表/实参表，; 结束声明与语句，: **文法未使用** |
| ( ) [ ] { } | L/R_PARENTHESE L/R_BRACKET L/R_BRACE | 括号、函数定义标记 -[ 与 ]、数组声明与下标（§2.4）、复合语句花括号 |

### 1.6 词法错误处理

词法层不返回「错误记号」：非法记号被报告为 [Error] 并**丢弃**，扫描从当前字符继续（lexer.cpp:78-81）。这样单个坏字符不会阻塞后续解析。

## 2. 类型

### 2.1 可声明的类型

int、char、void 三种。其中 void 只应作为函数返回类型使用（void v; 目前不报错，但没有任何操作能对它求值——见 §7）。

### 2.2 字面量类型

C_INTEGER、C_CHAR、C_STRING。声明类型与字面量类型是两套枚举，TypeUtil::canonical_type() 把它们归一：C_INTEGER→int、C_CHAR→char、C_STRING→char。

### 2.3 相容规则（type_util.cpp）

操作数分两类：**地址值**（指针变量、数组名、存放地址的临时量）与**普通值**（基本类型变量、字面量、索引/解引用读出的内容）。判断只看类别，不看具体基类型：

- 两个**普通值**：一律相容。因此 int ← char、char ← int 都不报错，1 == "abc" 也不报错。
- 两个**地址值**：归一化基类型必须相等，int *p 不能接 char *q。
- 一个是地址值、一个是普通值：不相容，p = 42; 报 赋值的类型不正确。

比较运算（> < == …）对两个地址值要求基类型一致，对两个普通值一律放行，结果类型恒为 int。因此 p == &x 合法（§5 示例）。

### 2.4 指针与数组

声明支持两种引用类形式，都只有一层：

```
int a[5];      // 长度为字面量正整数的数组，元素占一个槽位
int *p;        // 单层指针，指向 int
```

- 数组长度必须是**字面量正整数**：int n = 5; int a[n]; 报 数组长度不符合规范；int a[2][3] 也一样被拒。
- 元素大小固定为一个槽位（8 字节），与基类型无关；数组整体在栈帧（局部）或 .zero 静态数据（全局）里连续排布，a[i] 的地址就是基址加 i 个槽位。
- 没有数组初始化语法，也没有数组赋值：int a[2] = {1,2}; 与 a = p; 都报错；只能逐元素写 a[0] = 1;。
- 数组名在表达式里**退化为首元素地址**（等价于 &a[0]），因此 p = a;、sum(a,2) 都成立；退化之后 a 与 p 用法一致。
- 指针的加减按元素（一个槽位）计：p + 1 前进 8 字节；两个地址相减 p - a 得到的是**元素个数差**，不是字节差。
- 解引用 *p 与下标 a[i] 都定位一个**存储单元**（cell），单元既可读也可写：*p = 42;、a[i] = v;、++a[i];、input a[i]; 都合法。
- &x、&a[i]、&*p 取到的就是那一格的地址；对字面量或临时量取地址报 左值表达式不正确。
- 运行时**不做越界检查**，越界读写直接落到相邻栈槽。

## 3. 文法

记法：::= 定义；| 选项；[ X ] 可选；X* 零或多次；<...> 非终结符；**粗体**为关键字；⟪记号⟫ 为词法记号类别。下面是等价的**抽象文法**，实现里是去掉左递归后的递归下降（每层右部写成 操作数 扩展 形式，见 parser.cpp）。

### 3.1 程序与顶层段

```
program        ::= segment*
segment        ::= type var_definition
                 | '-' '[' type ']' ID '(' parameter ')' function_content
                 | '-' '[' type ']' ID '(' parameter ')' ';'      # 只有原型
type           ::= **int** | **char** | **void**
```

顶层既可以是全局变量定义，也可以是函数；顺序任意，函数之间没有前后顺序要求（但被调用者必须先声明或先定义，见 §4.3）。
函数定义的引导符是字面上的 -[，类型用 [] 包起来：-[int] main()。这是实现的既有事实，不是笔误。

### 3.2 变量定义

```
var_definition ::= declarator [ '=' expr ] definition_tail
declarator     ::= [ '*' ] ID [ '[' ⟪C_INTEGER⟫ ']' ]
definition_tail::= ',' declarator [ '=' expr ] definition_tail | ';'
```

- 同一类型可用逗号串起多个声明符，指针与数组标记各自跟随自己的名字：int a = 1, *p, b[3];
- '*' 与 '[' 各自独立解析，写成 int *p[3]; 不报错，但它只是 3 个槽位的数组：单元里存的是普通值，p[0] = &x; 与 *(p[0]) 都取不到地址值，语言里没有二级指针的用法。
- 全局变量只允许用**字面量**初始化；int a = 1 + 2; 或 int h = g; 会报 全局变量无法初始化（表达式初始化需要落到函数指令流里，而全局作用域没有当前函数）。

### 3.3 函数

```
parameter        ::= parameter_item parameter_tail | ε
parameter_item   ::= type [ '*' ] ID       # 指针形参写 int *p，数组通过指针形参传入
parameter_tail   ::= ',' parameter_item parameter_tail | ε
function_content ::= block | ';'
```

- -[int] f(int a); 是**声明（原型）**；之后可以 -[int] f(int a) { ... } 补定义。
- 返回类型只能是 int / char / void，-[int *] f() 无法归约；数组与指针只能靠指针形参传出传进。
- 先声明后定义时，参数个数与相容类型必须一致，否则 重复定义函数；直接重复定义函数体也报 重复定义函数。
- 函数体不检查「非 void 函数是否所有路径都 return」；漏写 return 时按 OP_RETURN（无值）落到出口。

### 3.4 语句与复合语句

```
block       ::= '{' sub_program '}'
sub_program ::= ( var_definition_with_type | statement )*
statement   ::= while_stmt
              | if_stmt
              | 'break' ';'
              | 'continue' ';'
              | 'return' [ expr ] ';'
              | 'input' lvalue ';'            # 读进一个可写单元
              | 'output' expr ';'             # 打印一个表达式
              | expr ';'                    # 表达式语句
              | ';'                         # 空语句
while_stmt  ::= 'while' '(' [ expr ] ')' block
if_stmt     ::= 'if' '(' expr ')' (block | statement) [ 'else' (block | statement) ]
lvalue      ::= expr                        # 文法上就是完整表达式，左值属性在生成阶段检查
```

- 声明可以穿插在语句之间（没有 C89 那样「声明必须在前面」的限制）。
- while 的循环体**必须是块**；if 的两个分支可以是块或单条语句，else 就近匹配最近的未匹配 if。
- 裸块 { ... } **不能当语句用**：statement 没有 block 分支。
  
  { int a = 1; }   -> [Error] Line 2:6 '}'符号处于不正确位置，或无法识别 ...
  
- break/continue 只在最近的 while 上下文中合法，否则报 break关键字没有处于while语句下 / continue关键字没有处于while语句下。
- while(1) 或 while(x) 这类非比较条件合法：条件只要是非 void 表达式即可，void 条件被强制当作真。
- input 的右侧是完整表达式，但必须落在一个**可写存储位置**：input x;、input a[i];、input *p; 都合法，各自生成一条 OP_READ（对 a[i]、*p 这样的单元，写入地址就是它定位出的地址）。input 3; 与 input a + b; 报 左值表达式不正确: input 的目标必须是可写的存储位置，input zz;（未声明）报 使用未定义变量。
- output 的右侧是完整表达式链，含赋值：output a * b + 1; 与 output a = 3; 都合法，后者先赋值再打印；字符串字面量也可以直接输出。生成一条 OP_PRINT。void 表达式被拒：output; 报 表达式使用了返回值为void的函数。
- 两条语句都不自动换行，也不接受格式串；输出形式由操作数的字面类型决定（char 用 %c，字符串用 %s，其余用 %lld），见设计文档 §3.10。

### 3.5 表达式

```
expr          ::= assign_expr
assign_expr   ::= or_expr [ '=' assign_expr ]                 # 结果再向右扩展，故 a = b = 7 成立
or_expr       ::= and_expr ( '||' and_expr )*
and_expr      ::= compare_expr ( '&&' compare_expr )*
compare_expr  ::= arith_expr ( ( '>' | '>=' | '<' | '<=' | '==' | '!=' ) arith_expr )*
arith_expr    ::= item ( ( '+' | '-' ) item )*
item          ::= factor ( ( '*' | '/' | '%' ) factor )*
factor        ::= ( '!' | '-' | '++' | '--' | '&' | '*' ) factor
                | auto_inc_dec
auto_inc_dec  ::= element [ '++' | '--' ]
element       ::= ID id_extend
                | '(' expr ')'
                | ⟪C_INTEGER⟫ | ⟪C_CHAR⟫ | ⟪C_STRING⟫
id_extend     ::= '(' [ argument_list ] ')'                   # 函数调用
                | '[' expr ']'                                # 下标，见 §2.4
                | ε                                           # 取变量值
argument_list ::= expr ( ',' expr )*
```

要点：

- **没有一元 +**：+ 只出现在二元位置。y = -x + +a; 里 +a 无法归约，报 常量定义处于不正确位置，或无法识别:+，整条语句被错误恢复丢弃。
- 赋值号左边必须是左值：普通变量、a[i]、*p 都可以；字面量、函数调用结果、临时量作左值时报 左值表达式不正确（1 = 2;），数组名作左值时报 左值表达式不正确: 数组名不可赋值。
- 比较运算是左结合且**可连写**：1 > 2 == 0 解析为 (1 > 2) == 0。
- 前缀 ++ -- 结合到整个 factor（右结合），后缀 ++ -- 只贴住一个 element，因此 -a++ 解析为 -(a++)。++/-- 对 a[i] 与 *p 同样成立：先读出单元的值，算完再写回同一格。
- 每个参与运算的操作数都会先做一次**取值归一**（ir_generator 的 value_of）：单元（a[i] / *p）生成 OP_PTR_GET 读成普通值，数组名退化成 OP_LEA，指针变量按地址值原样使用。因此 output *p; 与 a[i] = *p + 1; 都不需要额外的括号。
- 函数调用作为**语句**使用是合法的（p(3); 走表达式语句分支，生成 arg 3 ; p( 即 OP_PROC），void 函数因此可以正常调用；但一旦结果参与运算就被拒：a = h(); 与 output h(); 都报 表达式使用了返回值为void的函数，声明时初始化 int z = h(); 则报 变量无法赋初值（调用本身仍会执行）。

### 3.6 优先级与结合性

从低到高：

| 优先级 | 运算 | 结合性 |
|---|---|---|
| 1 | = | 右结合（实现为「先递归取右侧，再对结果扩展」） |
| 2 | \|\| | 左 |
| 3 | && | 左 |
| 4 | > >= < <= == != | 左（允许连写） |
| 5 | + -（二元） | 左 |
| 6 | * / % | 左 |
| 7 | ! -（一元）++ --（前缀） & *（一元） | 右 |
| 8 | ++ --（后缀） | 非结合 |
| 9 | ( ... )、字面量、ID、调用、[ ] 下标 | — |

短路语义：&&、|| 生成的是 OP_AND/OP_OR 三地址指令，**不是条件跳转**，两侧都会被求职。

## 4. 语义约束

### 4.1 作用域

- 作用域是词法的、嵌套的：文件级为第 1 层，函数体、每个 {} 块各加一层；形参在函数自身作用域。
- 变量按「作用域路径」（vector&lt;int>）保存与查找：同名变量在**同一层**重复定义报 重复定义变量；在**内层**定义则遮蔽外层，合法。
  
  int a = 1;
  -[int] main(){
      int a = 2;          // 遮蔽全局 a，合法
      if (1) { int a = 3; a = a + 1; }   // 再遮蔽一层
      a = a + 1;          // 这里用的是 main 的 a
      return a;
  }
  
- 兄弟块可以各自定义同名变量（块的编号单调递增，互不冲突）。
- 查找取「在当前上下文里能匹配到的最长作用域前缀」，即就近可见原则。

### 4.2 初始化

- 声明时可带字面量初值，int c = 'A'; 直接把值折进变量记录（OP_DECLARE 不再生成赋值）。
- 局部变量用表达式初始化时，额外生成一条 ASSIGN（先声明、后赋值）。
- 使用未定义变量：使用未定义变量。

### 4.3 函数

- 单名字表：同名函数只保留一个条目，靠参数列表区分，**不构成真正的重载**（同名不同参的第二定义报 重复定义函数）。
- 调用点在解析时立即查表，因此必须「先声明/定义，后使用」：
  
  -[int] use(){ return later(1); }     // [Error] 使用未定义的函数
  -[int] later(int a){ return a; }
  
  改成在 use 前加一句原型 -[int] later(int a); 即可（走 -S / -o 出汇编时会失效，见 §7.10）。
- 实参与形参按位置逐个做 §2.3 的相容检查，个数或类型不符报 函数的形参列表和实参列表不匹配。
- 允许递归（fact(n) 调用自身，因为定义时函数名已入表）。
- 只有原型、没有定义的那一句本身是安全的（优化器会跳过没有指令流的原型），但调用它要到链接阶段才暴露，见 §7.11。

### 4.4 返回值

- return e;：e 为 void（如 void 函数调用结果）时报 返回值与声明不匹配。
- return;：只有 void 函数合法。
- 非 void 函数体执行不到 return 时不报错，返回值为未定义存储。

## 5. 完整示例

以下程序可无错编译（shaolang demo.sl），覆盖了本文大部分规则：

```
int base = 10;

-[int] add(int x, int y) {
    return x + y;
}

-[int] calc(int n) {
    int sum = 0;
    int i = 1;
    while (i <= n) {
        sum = sum + add(i, base);
        i++;
    }
    output sum;
    if (sum > 100)
        return sum;
    else
        return 0;
    return i;
}

-[int] main() {
    int n;
    input n;
    return calc(n);
}
```

数组与指针的写法同样可无错编译，输出 60 与 15：

```
-[int] total(int *items, int n) {
    int sum = 0;
    int i = 0;
    while (i < n) {
        sum = sum + items[i];
        i++;
    }
    return sum;
}

-[int] main() {
    int scores[3];
    scores[0] = 10; scores[1] = 20; scores[2] = 30;
    int *cursor;
    cursor = scores;                 // 数组名退化为首元素地址
    output total(cursor, 3);
    output "\n";
    *cursor = *cursor + 5;           // 直接改写 scores[0]
    output scores[0];
    return 0;
}
```

最小合法程序：

```
-[void] main() { }
```

## 6. 非法 / 不推荐写法速查

均在当前构建上实测。

| 写法 | 现象 | 原因 |
|---|---|---|
| input 3; | 左值表达式不正确: input 的目标必须是可写的存储位置 | input 接受左值表达式，字面量与临时量不可写（§3.4） |
| input zz;（zz 未声明） | 使用未定义变量 | get_variable 查不到即报错，语句不生成 OP_READ |
| output; | 表达式使用了返回值为void的函数 | all_expr 失败返回 voidVariable，generate_print 拒绝 void |
| int n = 3; int a[n]; | 常量定义处于不正确位置 + 数组长度不符合规范 | 长度只接受字面量正整数（§2.4） |
| char s[2][3]; | 变量或函数定义不正确 | 只有一维数组 |
| a = p;（a 是数组名） | 左值表达式不正确: 数组名不可赋值 | 数组不能整体赋值、整体比较 |
| -[int *] f() | ']'符号处于不正确位置 | 返回类型只能是 int / char / void |
| p[0] = &x;（p 声明为 int *p[3]） | 赋值的类型不正确 | 单元存的是普通值，没有二级指针用法 |
| { int a = 1; } 作语句 | '}'符号处于不正确位置 | statement 无 block 分支 |
| +a（一元正号） | **静默丢弃整条赋值语句**，无报错 | factor 未列 ADD |
| 1.5 | ShaoLang不支持浮点数 | 无浮点类型 |
| 2fast | ShaoLang不允许使用数字作为标识符的开头 | 标识符规则 |
| a \| b | 符号'\|'不是ShaoLang可用的运算符 | 只有 \|\| |
| void 调用的结果参与运算（a = h(); / output h();） | 表达式使用了返回值为void的函数 | void 调用返回 voidVariable，任何二元/一元运算都拒绝 void；写成语句 h(); 则合法 |
| int z = h();（用 void 调用初始化） | 变量无法赋初值 | 声明期初始化走类型相容检查；调用仍会生成 OP_PROC |
| -[int] helper(int x); 而没有函数体 | 编译通过，调用它时链接失败 | 原型没有指令流，未定义符号要到链接阶段才暴露（§7.11） |
| 1 = 2; | 左值表达式不正确 | 字面量非左值 |
| int h = g;（全局） | 全局变量无法初始化:h | 全局作用域没有指令流承载赋值 |
| a = main(); 且 main 返回 void | 表达式使用了返回值为void的函数 | 同 void 规则 |
| 裸 break; / continue;（不在 while 内） | break关键字没有处于while语句下 | 跳转链栈为空 |

## 7. 已知语法/语义缺口

按影响程度排序，均为代码事实而非推测：

1. **输入输出的形状很窄**：input 一次只写一个可写单元（变量、a[i]、*p），没有批量读入；output 不自动换行、不接受格式串。
2. **表达式语句的结果一律丢弃**：3 + 4; 合法，只留下一个没人用的临时量（常量传播后变成 .L1 = 7），没有「无用表达式」警告，也没有对返回值的任何检查。
3. **引用类型只有一层，且不检查越界**：数组只支持一维、长度必须是字面量，没有初始化列表、没有整体赋值；指针没有二级解引用、不能作返回类型；a[i] 的下标在运行时不做边界检查，越界直接读写相邻槽位。
4. **一元 + 缺失**：+ 只出现在二元位置，y = -x + +a; 报 常量定义处于不正确位置，语句被错误恢复丢弃；generate_two_value_op 在操作数为 NULL 时仍只返回 NULL（ir_generator.cpp:26），是否报错取决于上层是否已经报告过。
5. **void 局部变量声明不报错**：VARIABLE_CAN_NOT_BE_VOID 只在一元运算路径与 generate_read 里检查，void v; 本身能通过。
6. **无重载**：函数表单槽位只按名字存，多参数组只能保留第一个。
7. **无块语句、无 for、无 switch、无 do-while、无 struct、无位运算、无类型转换语法**。
8. **错误定位偏后**：诊断打印的是扫描器**当前读到**的位置，而不是出错构造的起始位置；一条错误常出现在问题语句之后的行/列上（error.cpp:28-31）。
9. **错误不终止编译**：报告完继续走完解析与优化，退出码仍是 0，只有命令行本身不合法才返回 2；带 -S 或 -o 时，有错的源文件直接不出目标代码（源文件存在错误，没有生成目标代码）。
10. **原型 + 后补定义会在汇编里把形参读成 0**：定义沿用的是原型那个函数符号的形参列表，函数体里解析到的却是定义新注册的另一个同名变量，于是帧槽布局与使用错位。IR 阶段结果完全正确，只有 -S / -o 才出错（设计文档 §5.9 有实测，-[int] helper(int x); 之后补定义再调用 helper(41) 实际得到 1）。前向引用因此仍不能真正靠原型解决——把定义写在前面才是可靠写法。
11. **调用只有原型、没有定义的函数只能在链接阶段发现**：编译器本身不报未定义（源文件里只写 -[int] later(int x); 且从不调用也能正常出可执行文件），调用它时链接器报未定义符号并给出「链接失败：…」，退出码仍是 0。
